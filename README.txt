ABRASHIN TECHNOVA — FRONT-END LANDING PAGE

Files:
- index.html : page structure and content
- style.css  : responsive layout, brand styling and animations
- script.js  : intro animation, mobile menu, scroll reveal and active navigation

How to run:
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

Customize before publishing:
- Replace the demo AT monogram in the header/hero/intro with your official Abrashin Technova logo.
- Replace hello@abrashintechnova.com with your actual business email.
- Add your real social media profile links and phone/WhatsApp details in the contact section.
- Replace the three concept project previews with screenshots of your actual work.
- Review the service list and edit it to match the services you currently offer.

Notes:
- This is a static front-end design only. It has no backend, contact form submission, CMS or database.
- Google Fonts are loaded from Google Fonts, so the chosen fonts need an internet connection.
- The first-visit intro is shown once per browser tab session. Refreshing the page after the intro will go straight to the site.
